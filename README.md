# 🚀 Algorithms & Problem Solving - Level 4 Solutions

This repository contains all solutions, algorithmic implementations, and practical projects for **Course 8: Algorithms & Problem Solving - Level 4** taught by **Dr. Mohammed Abu-Hadhoud** (Programming Advices).

This course focuses deeply on advanced programming logic, constructing a comprehensive **Date & Time Library** from scratch, **File Handling**, and building a granular **Bitwise Permissions System**, along with end-to-end console application projects.

---

## 🧠 Key Skills & Concepts Mastered

Throughout this course, the following advanced algorithms and engineering concepts were implemented:

### 1. Custom Date & Time Library

- **Leap Year & Calendar Math:** Checking leap years (`Leap Year`), calculating total days, hours, minutes, and seconds for any given year or month.
- **Calendar Generation:** Computing the day of the week (`Day of Week`) for any date and printing complete monthly/yearly calendars.
- **Date Conversions:** Converting dates to days from the beginning of the year and vice versa.
- **Date Arithmetic & Operations:** Adding and subtracting days, weeks, months, years, decades, and centuries while taking leap years and variable month lengths into account.
- **Date Comparisons & Differences:**
  - Calculating exact differences between two dates in days/minutes.
  - Calculating age in days.
  - Comparing dates (`Is Date 1 Before/Equal/After Date 2`).
- **Business & Vacation Logic:** Calculating business days, actual weekends, and computing effective vacation days between two dates.
- **Periods & Overlap Handling:**
  - Detecting overlap between two date periods (`Is Overlap Periods`).
  - Calculating period lengths and overlap durations.
  - Validating if a date falls within a specific period.
- **Validation & Formatting:** Date validation routines (`Validate Date`) and flexible date string formatting (`Format Date`).

### 2. Capstone Projects

The course features two end-to-end projects integrating core data structures, algorithms, and file operations:

#### 🏦 Bank System - Extension 2

- **Authentication System:** Secure login with user credentials and failed attempt tracking.
- **User Management (CRUD):** Full user administrative controls (Create, Read, Update, Delete).
- **Bitwise Permissions System:** Utilizing bitwise operations (`AND`, `OR`, `NOT`) to grant or restrict specific feature permissions per user.
- **Audit Logging:** Recording user access logs with precise timestamps to external files.

#### 🏧 ATM System

- Simulation of an ATM client portal reading and writing directly to persistent file storage.
- Features include Quick Withdraw, Custom Withdraw, Deposit, and Balance Inquiry operations.
